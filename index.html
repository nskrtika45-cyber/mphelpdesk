HelpDesk Setup

1. Load recommended masters

Adds the new statuses (Acknowledged, On Hold, Pending Approval, Rejected), the 10 ticket categories, any missing departments, and the department-wise Issue Types and Sub-Types from the requirement list. Existing Issue Types with the same name are linked to the department instead of duplicated. Nothing is deleted and existing tickets are not touched. Safe to run more than once.

2. Update existing tickets

Old tickets have no “Assigned Department”, so department users cannot see them. This sets the Assigned Department on old tickets only where it can be worked out from the ticket's Issue Type (after step 1). Nothing else on the tickets changes.
